Kebijakan Privasi

Aplikasi: A.R.C.A Relayer
Pembaruan Terakhir: 24 September 2026

Prinsip Utama Privasi: A.R.C.A Relayer dirancang dengan fokus utama pada privasi dan keamanan data pengguna. Aplikasi ini beroperasi secara lokal di perangkat Anda dan tidak pernah mengumpulkan, menyimpan, atau menjual data pribadi Anda ke server pihak ketiga mana pun.

1. Akses Izin Perangkat dan Penggunaannya

Untuk menjalankan fungsinya, A.R.C.A Relayer memerlukan beberapa izin khusus pada perangkat Android Anda:

  • Akses Notifikasi (Notification Listener Service): Digunakan khusus untuk membaca konten pesan masuk (seperti WhatsApp atau SMS) sesuai dengan konfigurasi yang Anda tentukan. Data notifikasi ini dibaca secara langsung di perangkat dan hanya digunakan untuk memicu integrasi Text-To-Speech (TTS) atau meneruskan payload pesan.
  • Text-To-Speech (TTS): Digunakan untuk membacakan isi notifikasi secara lokal di perangkat Anda. Audio dikonversi secara langsung di dalam sistem perangkat tanpa direkam atau dikirim keluar.
  • Akses Jaringan (Internet): Digunakan secara opsional hanya jika Anda mengonfigurasi endpoint API kustom milik Anda sendiri untuk meneruskan pesan (relay online).

2. Pengolahan Data dan Keamanan

  • Pengolahan Lokal: Seluruh pemrosesan teks, notifikasi, dan sapaan suara dilakukan secara 100% lokal di dalam perangkat Android Anda.
  • Transmisi API Mandiri: Jika fitur relay online diaktifkan, data notifikasi hanya dikirimkan ke alamat server API kustom yang diinput secara manual oleh Anda. Pengembang aplikasi tidak menyediakan server perantara, tidak mencatat log transmisi, dan tidak memiliki akses ke endpoint yang Anda gunakan.
  • Penyimpanan Data: Aplikasi ini tidak menyimpan riwayat pesan atau notifikasi dalam basis data eksternal pengembang.

3. Pembagian Data Pihak Ketiga

Kami tidak menjual, menyewakan, membagikan, atau mengalihkan data pribadi, konten notifikasi, atau informasi perangkat Anda kepada perusahaan, organisasi, atau individu pihak ketiga mana pun.

4. Penarikan Izin dan Penghapusan Data

Anda memegang kendali penuh atas izin aplikasi ini:

  • Anda dapat mencabut izin Akses Notifikasi kapan saja melalui menu Pengaturan Perangkat > Privasi > Akses Notifikasi.
  • Menghapus aplikasi (uninstall) akan membersihkan seluruh setelan dan konfigurasi lokal dari perangkat Anda secara permanen.
